# Arona Mini Pizza

One-page website for Arona Mini Pizza (Hermannstraße 168, Berlin-Neukölln and Reißeckstraße, am U-Bhf Alt-Mariendorf).

Built with React + Vite. The pizza images, the making-of film and the 3D tray are drawn in the browser with Canvas and Three.js.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # output in dist/
```

## Deploy on Vercel

Import this repository on vercel.com. Vercel detects Vite automatically (build command `npm run build`, output `dist`).
